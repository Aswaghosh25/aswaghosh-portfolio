# Aswaghosh S - Portfolio

A recruiter-focused personal portfolio for Aswaghosh S.

## Files
- `index.html` - website content
- `style.css` - design and responsive layout
- `script.js` - small interaction/animation script
- `assets/Aswaghosh-S-Resume.pdf` - CV used by the Download CV buttons

## Deploy with Vercel
1. Upload these files to your GitHub repository.
2. In Vercel, choose **Add New -> Project**.
3. Import the GitHub repository.
4. Click **Deploy**.
5. No build command is required for this static HTML/CSS/JS site.

- `assets/profile.jpg` - profile photo used in the hero card
