# Aswaghosh S — Portfolio

This is the source project for the portfolio website.

## Files
- `index.html` — page structure and content
- `css/style.css` — styling and responsive layout
- `js/main.js` — interactive behaviour and embedded resume download
- `assets/Aswaghosh-S-Resume.pdf` — latest standalone resume PDF

Images and logo artwork used by the page are embedded in the HTML/CSS, so no separate image folder is required.

## Publish with GitHub Pages
1. Extract the ZIP.
2. Upload the contents of this folder to the root of your GitHub repository (keep the `css`, `js`, and `assets` folders).
3. Commit and push the changes.
4. In GitHub, open **Settings → Pages**, select the branch and `/ (root)` folder, then save.
5. Open the published URL after GitHub Pages finishes deploying.

You can also deploy the same folder to Vercel by importing the GitHub repository. No build command is required; the site is static.
